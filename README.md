# 어디가지

조건으로 장소를 찾고, **왜 그런지 근거 링크까지 같이** 보여주는 도구.

## 왜 만들었나

맛집을 찾으려면 블로그 20개를 열어보고 "이게 협찬인가" 의심해야 한다.
그런데 "가평 + 한강뷰 + 3시간 노트북 작업 + 에어컨 + 예산" 같은 복합 조건은
어떤 검색창에도 넣을 칸이 없다.

## 접근

**협찬을 판별하지 않는다.** 대신 협찬 글에는 없는 정보만 뽑는다.

협찬 글은 "분위기 좋고 커피 맛있다"를 쓴다.
콘센트 개수, 에어컨 세기, 2시간 앉아 있어도 눈치 안 주는지는
실제로 그만큼 있어 본 사람만 쓴다.

질문을 구체적으로 하면 진짜 글만 남는다.

## 원칙

- 모든 주장에 **원문 링크 + 날짜**를 붙인다
- 모르는 건 "미확인"으로 표기한다. 추측으로 채우지 않는다
- 단점·지뢰를 먼저 보여준다
- 위치는 브라우저 안에서만 쓰고 전송하지 않는다

## 상태

| 기능 | 상태 |
|---|---|
| 내 위치 · 이동수단 · 시간 반경 · 거리 계산 | 동작 |
| 근거 링크 · 가격 · 지뢰 경고 | 동작 |
| 조건 넣으면 블로그를 새로 읽는 실시간 검색 | 백엔드 연결 대기 |

## 구조

```
index.html        UI
assets/app.js     위치·거리·이동수단·렌더
assets/app.css    스타일 (라이트/다크)
data/places.json  수집된 장소 + 근거
```

거리는 직선거리 × 1.35 도로보정, 도보 4.5km/h, 차 38km/h + 주차 2분 기준의 추정치다.
